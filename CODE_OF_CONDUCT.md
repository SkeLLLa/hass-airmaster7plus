# Code of Conduct

## Our Pledge

Treat others the way you expect to be treated.

## Our Standards

All behavior considered acceptable.

## Enforcement

Maintainers have the right to remove, edit, or reject comments, commits, and other contributions not aligned with this Code of Conduct.
